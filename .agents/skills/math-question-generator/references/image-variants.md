# 图片识读与变式

1. 从对话附件逐题识读。按题号分开题干、图形条件、印刷答案和学生笔迹。转写时保留分数线、指数作用范围、括号、正负号、单位和选项次序。图形只采信明确标注或文字给出的关系。
2. 如果题号有歧义，或不确定的字符会改变题意，展示已读出的局部表达式并请求更清楚的局部图或文字确认。同一批中题意清楚的其他题可以先处理。图中有姓名、学校或其他身份信息时，只提取与题目和作答有关的内容。
3. 从原题条件重新求解并核对作答可行性，再写主知识点、必需的关联点和核心解法。例题与指定范围冲突时，指出冲突并请用户选取同范围的目标或授权扩大范围。
4. 同类变式沿用核心解法，改数、结构、提问方式或情境。至少有一道变式改变干扰形式或条件排列。拓展题增加一层条件、改变已知与所求，或串联范围内已学的知识。每道题能单独阅读作答。需要说明差异时放到答案页。

七上第四章例题 `3x − (x − 4)` 考查括号前的负号。同类变式 `5x − (2x − 7)` 应得 `3x + 7`。范围内拓展 `3x − [2x − (x − 4)]` 应得 `2x − 4`，需要先处理内层括号，再处理外层负号。
